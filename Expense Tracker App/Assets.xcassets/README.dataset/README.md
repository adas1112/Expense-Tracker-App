# Expense Tracker SVG UI Assets

Standalone SVG assets generated to match the SpendWise poster visual style.

Folders are grouped by filename prefix:
- app_logo
- onboarding_*
- category_*
- payment_*
- navigation_*
- action_*
- status_*
- auth_*
- chart_*
- empty_state / savings_goal / receipt_scanner / budget_alert

## SwiftUI
You can use these SVGs with an SVG-capable asset/image package, or convert them to PDF/vector assets for an Xcode asset catalog.

## UIKit
Convert SVG to PDF or use an SVG rendering library, then load it as a UIImage.

All assets are individual files; no cropped poster images are included.
